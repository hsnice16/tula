# 0.2.0 — The shell

The daily driver. Users must stop thinking in platforms - that is the entire value
proposition - so the interactive surface is venue-agnostic by default. Venue-scoped
queries stay possible but are never the default; if the daily interface makes
someone pick a venue first, we have rebuilt their five browser tabs in one terminal.

The surface grew to include the agent: asking in plain English is the same shell,
not a later product. Structured commands stay authoritative — the model routes to
them, and everything works without an API key.
