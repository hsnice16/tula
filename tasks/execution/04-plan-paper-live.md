# 04 · Plan, paper, live

**Status**: planned

## Goal

A first-class interface state, not a configuration flag.

## Acceptance

- The current mode is always visible.
- Moving to live is a deliberate act with a confirmation, never a default.
- Paper mode uses the same execution path with a simulated venue. It never
  reaches the book: a stand-in account beside real ones is the thing this project
  removed once already (`tasks/foundations/05-demo-fixture.md`), so paper fills
  an order and states the result against the mode the reader is in, and no
  position, total or liquidation distance is computed from it.
- The first autonomous capability is defensive - repay before liquidation - not speculative.

## Notes

A defensive action has a clear right answer. "Trade for me" is gambling with
extra steps.
