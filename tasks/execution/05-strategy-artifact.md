# 05 · The strategy artifact

**Status**: planned

## Goal

No-code plus autonomous means the user cannot read what will run. They need
something human-readable, editable, and honest about what the agent will do.

## Acceptance

- A representation a non-programmer can read and edit with confidence.
- It says what will happen, not what might.
- Diffable, so a change to a strategy is reviewable.

## Notes

The hardest design problem in the project, and still open.
