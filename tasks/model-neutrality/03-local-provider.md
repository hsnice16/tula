# 03 · A provider that runs locally

**Status**: planned

## Goal

A model on the user's own machine, so the book never leaves it.

## Acceptance

- `localhost` is the sanctioned custom endpoint — the one case where a user-set
  URL is expected rather than confirmed as an exception.
- It passes [02](02-conformance-gate.md) like anything else, or it is not offered.
- Where tool calling is unreliable, the shell names the capability that is missing
  and what still works. Every view already has a command behind it.

## Notes

For a tool whose argument is that the keys and the book stay yours, a local model
is a better second provider than a second vendor.
